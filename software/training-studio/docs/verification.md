Linux 专用测试使用真实操作系统信号与 CPU 子进程，未模拟 `killpg` 或 `waitid`：

- SIGSTOP 后主进程及后代的计数器均冻结；SIGCONT 后继续增长。
- 暂停时关闭服务，拥有的进程组被清理。
- 主进程退出但后代仍持有 stdout 时，训练与评估任务都能结束并清理后代。

## 审核与修正

前后端分别经过独立规格审核与代码质量审核，最终均无阻塞项。审核中修复了配置不匹配仍可正式训练、检查点匹配不精确、暂停控制错误携带检查点参数、环境检测缓存不刷新、退出清理竞态、未完整写入的检查点、日志管道导致任务不结束、续训名称超长、导出遗漏评估证据和来源信息等问题。

## 验证边界

这些验证没有启动 NVIDIA GPU 训练。真实 CUDA 训练、GPU 视频渲染、ONNX 导出与推理仍需在目标云电脑进行短试跑和结果核对。适配已对照锁定的 mjlab 1.3.0 与 rsl-rl-lib 5.0.1 调用接口；这不等于证明机器人已经学会走路。

演示 ZIP 包不包含 PT/ONNX 权重。鸭子档案用于归档核对，不会自动改写物理模型。暂停不会关闭云电脑或停止云平台计费。
