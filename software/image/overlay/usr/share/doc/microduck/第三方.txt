Microduck Replica — Licenças de software de terceiros

Este arquivo lista os componentes de terceiros distribuídos junto com nossos programas na imagem. As licenças dos pacotes do sistema base (Armbian / Debian) ficam em `/usr/share/doc/<nome-do-pacote>/copyright` e não são repetidas aqui.

1. ONNX Runtime 1.28.0 (Microsoft)
-----------------------------------
Local: `/opt/robot/feetech-ft5-r5/onnxruntime/`. Licença MIT, redistribuído sem alterações.
Os avisos de terceiros que acompanham o runtime estão em `ThirdPartyNotices.txt`, no mesmo diretório.

2. Pacotes Python usados pelo Microduck Studio
----------------------------------
Local: `/home/radxa/studio-dev/deps/`. São arquivos wheel originais do pypi.org, extraídos sem alterações.
Versões e hashes SHA-256 estão em `deps/VERSIONS.txt`; o texto integral das licenças fica nos diretórios `*.dist-info` de cada pacote.
(O diretório `dist-info` do pyserial não contém o texto integral da licença; ele está anexado ao final deste arquivo.)

3. Bibliotecas de interface usadas pelo Microduck Studio
------------------------------
Local: `/home/radxa/studio-dev/web/vendor/`; o texto integral das licenças está em `web/vendor/licenses/`.

  Preact                   MIT
  htm 3.1.1                Apache-2.0
  three.js 0.160.0         MIT

4. Modelo 3D do pato usado pelo Microduck Studio
------------------------------------
Local: `/home/radxa/studio-dev/web/model/` (consulte `NOTICE.md` no mesmo diretório para a origem). As malhas vieram do CAD oficial do Microduck da Pollen Robotics, convertidas a partir do modelo de simulação do repositório `apirrone/microduck_rl`; somente as formas externas foram mantidas.
Assim como o modelo 3D upstream neste repositório `microduck-replica`, elas são tratadas sob CC BY-NC-SA 4.0 (atribuição, uso não comercial e compartilhamento pela mesma licença).

5. Bibliotecas Rust vinculadas estaticamente ao programa principal
-----------------------------
Os programas Rust em `/opt/robot/` (runtime oficial e nossos `robotd`, `padd` e `mediad`) incluem bibliotecas de código aberto do crates.io vinculadas estaticamente, em sua maioria sob licenças duplas MIT / Apache-2.0. A lista completa está no `Cargo.lock` do código-fonte correspondente.
