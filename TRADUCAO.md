# Tradução para português brasileiro

Este fork, [PedroTeruel/microduck-replica-ptbr](https://github.com/PedroTeruel/microduck-replica-ptbr), mantém a tradução em português brasileiro do projeto original [fanhao375/microduck-replica](https://github.com/fanhao375/microduck-replica). A tradução é mantida neste fork e não será enviada como pull request ao repositório original.

## Créditos e atribuição

- Projeto original e código: [fanhao375/microduck-replica](https://github.com/fanhao375/microduck-replica).
- Projeto upstream: [Pollen Robotics Microduck](https://github.com/pollen-robotics/microduck) e [microduck_rl](https://github.com/pollen-robotics/microduck_rl).
- CAD, BOM e material de montagem: **机械行者Robo**, conforme os créditos do projeto original e do repositório [microduck-replica-cad](https://github.com/fanhao375/microduck-replica-cad).
- Contribuidores, imagens, vídeos, modelos e demais autores continuam creditados nos arquivos de origem.

## Licenças

Os arquivos `LICENSE` e `NOTICE.md` são preservados sem tradução para manter os textos legais e as atribuições originais.

- A documentação geral e os textos de análise seguem **CC BY-NC-SA 4.0**, conforme `LICENSE` e `NOTICE.md`.
- `software/training/` mantém a exceção indicada pelo projeto: código, configuração, parâmetros e documentação nova seguem **Apache-2.0**; os modelos 3D preservam a licença upstream indicada nos próprios avisos.
- Código, modelos, imagens oficiais, dependências vendorizadas, firmware e ferramentas de terceiros mantêm as licenças próprias. A tradução não altera essas licenças.
- O conteúdo traduzido é uma adaptação linguística. A atribuição, a licença e o aviso de que o projeto não é afiliado nem endossado pela Pollen Robotics permanecem válidos.

## Preservação

Comandos, identificadores, caminhos de arquivos, URLs, imagens, vídeos, tabelas de créditos e referências a licenças devem permanecer funcionais na tradução. Quando uma âncora original é usada por links existentes, ela é preservada no README em português.
