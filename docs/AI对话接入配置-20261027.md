# Configuração de integração com conversa por IA

A primeira versão permite salvar uma conexão com um modelo e, depois de contratar o serviço, testá-la com uma conversa por texto. **Ainda não há integração com o microfone, alto-falante, voz em tempo real nem acionamento de movimentos por IA no robô.** Selecionar uma conexão atual não altera os recursos existentes de R3, os comandos locais para sentar / levantar nem a música.

Instalada em 2026-10-27 no duck-0de6; consulte [implantação e registro de validação](superpowers/verification/2026-10-27-ai-provider-settings.md). É possível salvar um rascunho antes de ter uma conta ou chave de API real.

## Começar pela interface web

Abra `http://duck-0de6:8000/#/settings`, entre e use o cartão “Conversa por IA”, que aparece perto do início da página. O painel “Interação por voz e música” também tem um atalho para as configurações.

1. Clique em “Nova conexão” e informe um nome.
2. Escolha o provedor e informe o endereço base e o ID do modelo. Sem uma conta, preencha apenas o nome e salve como rascunho.
3. Depois de contratar o serviço, informe a chave de API na interface web e salve. Não envie a chave pelo chat.
4. Com os dados completos, selecione “Definir como atual”. “Testar conexão” envia uma solicitação real e curta ao modelo.
5. Envie uma mensagem em “Conversa por texto” e confira a resposta. As respostas por texto não controlam o robô.

É possível salvar até 10 conexões. Salvar, editar ou selecionar uma conexão não acessa a nuvem automaticamente. Se faltar um campo necessário, a interface informa o que falta e bloqueia o teste e a conversa. A conexão atual permanece selecionada após reiniciar o serviço web.

## Dois tipos de provedor

| Opção | Endereço base e modelo |
|---|---|
| Doubao · modelo de texto Ark | O endereço `https://ark.cn-beijing.volces.com/api/v3` já vem preenchido. Informe o ID do modelo ou do ponto de entrada de inferência e a chave de API obtidos no próprio console Ark. Não são os dados de login do aplicativo móvel Doubao. |
| Outro endpoint compatível com OpenAI | Informe o endereço base HTTP(S), o nome do modelo e a chave fornecidos pelo serviço; o programa acrescenta `/chat/completions`. HTTP e a opção “sem chave de API” só podem ser usados com um serviço local explícito. |

A voz em tempo real Doubao 3.0 usa outra interface WebSocket e outro protocolo de eventos. O endereço da voz em tempo real ou a chave do serviço de áudio não podem ser usados como se fossem um endpoint de texto comum. Esta versão não afirma oferecer esse suporte; a integração de voz será feita separadamente.

As solicitações são enviadas pelo backend web do robô. Para usar um modelo na nuvem, o próprio robô precisa ter acesso à internet; o celular ou computador que abre o painel também precisa alcançar o robô. A disponibilidade do modelo depende das permissões da conta do usuário, do ID informado e da resposta real da interface.

## Armazenamento da chave e das conversas

- A chave é guardada no arquivo privado `ai-connections.json` do robô Linux, com permissão 0600, sem criptografia adicional. A leitura da configuração informa apenas se há uma chave salva, sem devolver seu conteúdo completo; a chave não vai para o armazenamento local do navegador, logs ou pacote de diagnóstico.
- Ao editar o mesmo provedor e endereço, deixar o campo da chave vazio preserva a chave salva. Trocar de provedor ou endereço não reutiliza a chave anterior silenciosamente. É possível apagá-la explicitamente ou escolher um serviço local sem chave.
- Depois de salvar, o campo da chave é limpo. A imagem de sistema inicial não contém chaves de ninguém; a atualização de software preserva as configurações locais do usuário. Cópias de segurança que contenham configurações privadas devem continuar protegidas.
- O histórico da conversa por texto permanece apenas na memória da página atual. Trocar, editar a conexão ou sair das configurações apaga o conteúdo; nenhum arquivo de histórico é gravado. A entrada aceita até 2.000 caracteres, a resposta até 4.000, e o contexto recente é mantido em turnos completos, até um total de 12.000 caracteres.

## Mensagens comuns

| Mensagem | Próximo passo |
|---|---|
| Faltam dados | Preencha o ID do modelo, o endereço ou a chave e salve novamente. |
| Chave de API inválida ou serviço não contratado | Confira se a chave pertence ao provedor selecionado e se o serviço correspondente está ativo. |
| O provedor recusou o acesso | Confira as permissões da conta para o modelo escolhido. |
| Modelo ou caminho da interface não existe | Confira o ID do modelo e a URL base; não inclua `/chat/completions` duas vezes. |
| Limite de solicitações ou saldo insuficiente | Confira os créditos e limites no console do provedor. |
| Solicitação expirou ou conexão interrompida | Verifique a rede do robô, o endereço do serviço e o estado do provedor; depois tente novamente. |
| A conexão foi alterada | A configuração mudou durante a solicitação; o resultado antigo não será tratado como sucesso da nova configuração. Atualize a página e teste de novo. |

“Teste bem-sucedido” significa apenas que aquela solicitação recebeu uma resposta normal; não comprova conexão contínua, funcionamento de voz no hardware ou compatibilidade com todos os modelos. Não havia uma chave real de usuário disponível para a validação; os testes de desenvolvimento usaram um provedor local simulado. O comportamento real na nuvem precisa ser validado após a contratação do serviço.

## Referências e próximos passos

Esta versão se inspirou na separação de configurações de reconhecimento, conversa e síntese de voz do Xiaozhi e implementou uma gestão simples de conexões no Studio existente. Ela não instala um servidor Xiaozhi completo no RK3566. No futuro, será possível adicionar separadamente a captura do microfone, o reconhecimento completo / voz em tempo real, a saída pelo alto-falante e uma interface restrita para ações.

- [Código-fonte da configuração do servidor Xiaozhi](https://github.com/xinnan-tech/xiaozhi-esp32-server/blob/main/main/xiaozhi-server/config.yaml)
- [Exemplo oficial de chamada do Doubao Ark](https://docs.volcengine.com/docs/ark/context-management?lang=en)
- [Interface oficial de voz em tempo real Doubao 3.0](https://docs.volcengine.com/docs/DoubaoVoice/endtoend-realtime-voice-full-duplex-version?lang=en)

O recurso está registrado no inventário de software F26. O acompanhamento musical e os problemas do modelo corporal continuam em seus registros originais; a página de configuração da IA não significa que esses problemas foram resolvidos.
