# AI对话接入配置

第一版用于先保存模型连接，开通服务后测试和文字试聊。**尚未接通鸭子的麦克风、扬声器、实时语音或AI动作调用。** 选择当前连接不会改变现有R3、本地坐站口令或音乐功能。

2026-10-27已安装到duck-0de6；[部署与验证记录](superpowers/verification/2026-10-27-ai-provider-settings.md)。没有真实账号或Key时，可先保存草稿。

## 从网页开始

打开 `http://duck-0de6:8000/#/settings`，登录后在靠前的“AI 对话”卡片操作。原“语音与音乐互动”面板也有设置入口。

1. 点“新建连接”，填写名称。
2. 选择提供商，填写基础地址、Model ID。没有账号时可先填名称并保存草稿。
3. 开通服务后在网页填写API Key，保存。Key不用发到聊天里。
4. 完整配置可“设为当前”；点“测试连接”会发送一次很短的真实模型请求。
5. 在“文字试聊”中发送消息，看模型是否正常回答。文字回复不会驱动机器人。

最多保存10套连接。保存、编辑和选择不会自动访问云端；缺少必要字段时明确显示待补齐，不能测试或试聊。当前选择会随网页服务重启保留。

## 两类提供商

| 选择 | 基础地址与模型 |
| --- | --- |
| 豆包·方舟文字模型 | 已预填`https://ark.cn-beijing.volces.com/api/v3`；Model ID或推理接入点ID、API Key从自己的方舟控制台填写。不是豆包手机App登录信息。 |
| 其他OpenAI兼容接口 | 填服务提供的HTTP(S)基础地址、模型名与Key；程序追加`/chat/completions`。仅明确的本地服务可用HTTP和“无需API Key”。 |

豆包实时语音3.0使用另一套WebSocket接口和事件协议，不能将实时语音地址或音频服务Key当成普通文字接口。本版没有假装支持它；后续会单独做语音适配。

请求由鸭子上的网页后端发出。使用云端模型时，鸭子自己需要能上网；手机或电脑访问控制网页还需能连到鸭子。模型是否可调用，以用户自己的账号权限、Model ID和接口实际响应为准。

## Key和对话如何保存

- Key存鸭子本机私有`ai-connections.json`，Linux权限0600，未做额外加密。读取配置只返回是否已保存，不返回完整Key；不进入浏览器localStorage、日志或诊断包。
- 同一提供商和地址编辑时，Key输入留空会保留已存Key；更换提供商或地址不会悄悄带用旧Key。可勾选清除，或明确选择本地免Key服务。
- 保存后输入框清空。新的基础镜像不包含任何人的Key；软件升级保留本机用户配置，备份含私人配置时应保持私有权限。
- 文字上下文仅保留在当前页面内存中；切换、修改连接或离开设置页会清空，不写入聊天记录文件。输入最多2000字，模型回复最多4000字，近期上下文按完整轮次保留，合计最多12000字。

## 常见反馈

| 提示 | 下一步 |
| --- | --- |
| 待补齐 | 填写Model ID、地址或Key，再保存。 |
| API Key无效或尚未开通 | 核对Key属于当前提供商，已开通相应服务。 |
| 提供商拒绝访问 | 核对所选模型的账号权限。 |
| 模型或接口路径不存在 | 核对Model ID及基础URL，避免重复填写`/chat/completions`。 |
| 限流或余额不足 | 到自己的提供商控制台核对额度和调用限制。 |
| 请求超时或连接中断 | 检查鸭子网络、服务地址和提供商状态，再重试。 |
| 连接已更改 | 配置在请求期间被修改，旧结果不会当成新配置的成功；重新读取后再测。 |

“测试成功”仅表示那一次请求正常回答，不表示持续连接、硬件语音或所有模型都已验收。当前没有用户真实Key，开发检查使用本地模拟提供商，真实云端效果需开通后验证。
