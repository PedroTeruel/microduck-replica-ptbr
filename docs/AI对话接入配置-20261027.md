# AI对话接入Configuração

第一版usado para先保存ModeloConexão，开通Serviço后Testee文字试聊。**尚未接通鸭子 de 麦克风、扬声器、实时语音或AI动作调用。** 选择AtualConexão不会改变现有R3、本地坐站口令或音乐功能。

2026-10-27已Instalação到duck-0de6；[部署 e Registro de validação](superpowers/verification/2026-10-27-ai-provider-settings.md)。没有真实账号或Key时，可先保存草稿。

## 从Web开始

打开 `http://duck-0de6:8000/#/settings`，登录后在靠前的“AI 对话”卡片操作。原“语音与音乐互动”面板也有设置入口。

1. 点“新建Conexão”，填写名称。
2. 选择提供商，填写基础地址、Model ID。没有账号时可先填名称并保存草稿。
3. 开通Serviço后在Web填写API Key，保存。Key不用发到聊天里。
4. CompletoConfiguração可“设为Atual”；点“TesteConexão”会发送一次很短 de 真实ModeloPor favor求。
5. 在“文字试聊” em 发送消息，看Modelo是否正常回答。文字回复不会驱动机器人。

最多保存10套Conexão。保存、编辑e选择不会自动访问云端；缺少必要字段时明确显示待补齐，不能Teste或试聊。Atual选择会随WebServiço重启Preservado。

## 两类提供商

| 选择 | 基础地址 e Modelo |
| --- | --- |
| 豆包·方舟文字模型 | 已预填`https://ark.cn-beijing.volces.com/api/v3`；Model ID或推理接入点ID、API Key从自己的方舟控制台填写。不是豆包手机App登录信息。 |
| 其他OpenAI兼容接口 | 填服务提供的HTTP(S)基础地址、模型名与Key；程序追加`/chat/completions`。仅明确的本地服务可用HTTP和“无需API Key”。 |

豆包实时语音3.0使用另一套WebSocket接口e事件Protocolo，不能将实时语音地址或音频ServiçoKey当成普通文字接口。本版没有假装suporta它；后续会单独做语音适配。

Por favor求由鸭子Superior de Web后端发出。使用云端Modelo时，鸭子自己é necessário能Superior网；手机或电脑访问ControleWeb还需能连到鸭子。Modelo是否可调用，以Usuário自己 de 账号权限、Model IDe接口实际响应为准。

## Keye对话如何保存

- Key存鸭子本机私有`ai-connections.json`，Linux权限0600，未做额外加密。读取配置只返回是否已保存，不返回完整Key；不进入浏览器localStorage、日志或诊断包。
- 同一提供商e地址编辑时，Key输入留空会Preservado已存Key；更换提供商或地址不会悄悄带用旧Key。可勾选清除，或明确选择本地免KeyServiço。
- 保存后输入框清空。新 de 基础Imagem不包含任何人 de Key；Software升级Preservado本机UsuárioConfiguração，备份含私人Configuração时应保持私有权限。
- 文字SuperiorInferior文仅Preservado在AtualPágina内存 em ；切换、修改Conexão或离开设置页会清空，不Gravação聊天记录Arquivo。输入最多2000字，Modelo回复最多4000字，近期SuperiorInferior文按Completo轮次Preservado，合计最多12000字。

## 常见反馈

| 提示 | Inferior一步 |
| --- | --- |
| 待补齐 | 填写Model ID、地址或Key，再保存。 |
| API Key无效或尚未开通 | 核对Key属于Atual提供商，已开通相应Serviço。 |
| 提供商拒绝访问 | 核对所选Modelo de 账号权限。 |
| 模型或接口路径不存在 | 核对Model ID及基础URL，避免重复填写`/chat/completions`。 |
| 限流或余额不足 | 到自己 de 提供商Controle台核对额度e调用限制。 |
| Por favor求超时或Conexão em 断 | Verificação鸭子Rede、Serviço地址e提供商状态，再重试。 |
| Conexão已更改 | Configuração在Por favor求期间被修改，旧Resultado不会当成新Configuração de Sucesso；重新Leitura后再测。 |

“TesteSucesso”仅表示那一次Por favor求正常回答，不表示持续Conexão、Hardware语音或所有Modelo都已验收。Atual没有Usuário真实Key，开发Verificação使用本地模拟提供商，真实云端效果需开通后Validação。
