## 方法

`scripts/analyze_holes.py`：

1. 焊接重复顶点，建面片邻接图
2. 按二面角 35° 切割，region-grow 出「光滑曲面片」（锐边处断开）
3. 每片拟合圆柱 —— 圆柱面法向都垂直于轴，所以**轴 = 法向协方差矩阵 de 最小特征向量**
4. 顶点投影到垂直轴 de 平面，Kåsa 代数圆拟合求直径，相对残差 >3%  de 丢弃
5. 法向指向轴心 = **孔**；背离轴心 = 轴/凸台，排除
6. 统计包角，只Preservado ≥300°  de Completo圆孔

47 个零件全部扫描，耗时 2.5 秒。

## 结论：整机是 M2 螺丝系统

结构件SuperiorCompleto圆孔 de 直径分布：

| 直径 | Quantidade | 判读 |
|---|---|---|
| **Ø2.2** | **77** | **M2 过孔**（标准 M2 clearance 2.2–2.4） |
| **Ø4.4** | **28** | **M2 沉头孔**（M2 内六角柱头 Ø3.8，沉孔 4.0–4.5） |
| **Ø1.6** | **20** | **M2 攻丝底孔**（M2 标准底孔正好 1.6） |
| Ø2.4 | 22 | M2 松配过孔 |
| Ø2.0 | 12 | M2 紧配过孔 |
| Ø2.7 / Ø2.8 | 20 | M2.5 过孔（少量） |
| Ø4.8 | 10 | M2 沉头孔（另一种沉孔深度） |
| Ø5.4 / Ø6.0 | 16 | 轴孔 / 轴承座，非螺丝 |

**Ø2.2 与 Ø4.4 成对出现**在 `yaw2roll`、`leg`、`ankle_left`、`neck_pitch`、`yaw_roll_motion` 上 ——
这是典型 de **过孔 + 沉头孔**组合，确认用 de 是 **M2 内六角圆柱头螺丝**。

交叉验证：`xl330.stl` 自身有 **Ø2.0×4 + Ø1.6×8**，与 Dynamixel XL330 的 M2 安装孔一致。

## ⚠️ 局限性

1. **这是从仿真网格反推 de ，不是工程图纸。** 仿真网格只保证外形 e 惯量正确，
   不保证配合公差、螺纹细节Completo。
2. **打印收缩会改变实际孔径。** Ø2.2  de 设计孔在 FDM Superior通常打出来偏小 0.1–0.3mm，
   实际装配前务必先打试件校验。
3. **沉头孔 e 过孔可能被重复计数**（同一颗螺丝 de 两个特征），
   螺丝Quantidade以「过孔」为准，沉头孔不单独计。
4. **未识别 de 特征**：非圆形孔（腰孔、异形槽）、包角 <300°  de 部分圆弧、
   直径 >14mm  de 大开口均不在统计内。
5. 螺丝**长度**是按孔深推算 de 区间，非实测值。
