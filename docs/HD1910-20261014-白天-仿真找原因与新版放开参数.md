## 1. 仿真怎么做 de ，跟真机差在哪

- **模型**：kissqy 的行走模型，就是真机上跑的那个 `walk/policy.onnx`，一点不改；
- **仿真**：官方训练工程 0.15.1 的场景 `scene_backlash.xml`（带齿隙），舵机用 BAM（舵机的物理模型）。我们在本地改了训练工程里的推理脚本，加了几个开关：换舵机参数文件、限制舵机输出上限（仿真里对应转矩限制）、给躯干加重、改脚底和地面的摩擦、头腿滤波（跟 robotd 一样：每拍「新目标 = α × 模型目标 + (1 − α) × 上一拍目标」）；动作缩放是脚本原来就有的参数。**这个脚本只在本地，没放进仓库**，命令是这样的（方括号里是按需加的）：

  ```
  HEADLESS=1 SIM_SECONDS=24 BAM_JSON=<舵机参数 json> MAX_PWM=0.7 \
    [EXTRA_MASS_G=83] [FRICTION=0.3] [HEAD_LOWPASS=0.5 LEGS_LOWPASS=0.7] \
    python infer_policy_kq_cmp.py --walking walk/policy.onnx --new-cmd-obs \
      --lin-vel-x 0.2 --kp-fw 4 --action-scale 0.83 \
      --scene src/mjlab_microduck/robot/microduck/scene_backlash.xml --save-csv 输出.csv
  ```
- **怎么比**：仿真录的数据转成跟真机录像一样的格式，用同一套 [`tools/gait-analysis/`](../tools/gait-analysis/) 脚本分析；
- **真机对照**：10-14 凌晨 P4 / D0 / 681、IMU 已补 de 那组（[10-13 夜 §5.2](HD1910-20261013-夜-掉电-ServoD e 蹭地.md#52-几组Parâmetros对比每组走-842-秒)）。Atenção它只走了 12 秒（报告脚本建议 15 秒以Superior才可靠），转矩限制是 681，不是 700。

## 2. 对齐条件以后：撑地膝盖接近了，但仿真多出了颤

陆吾Parâmetros（kissqy 训练用 de 那份）、P4、输出Superior限 70%、0.2 m/s。Servo电压这一项没对齐（仿真 7.4 V，真机约 8.0 V）：

| 仿真条件 | 撑地膝盖 Esquerdo / Direito（+ 是伸直） | 离地间隙 Esquerdo / Direito | 机身横滚晃动 | 其 em  >4 Hz（颤） | 步频 |
|---|---|---|---|---|---|
| 早Superior：缩放 1.0、不滤波、737 g | +3.5° / +6.5° | 12.7 / 11.9 mm | 36.5°/s | 8% | 3.14 Hz |
| 只把缩放改成 0.83 | −0.6° / +1.5° | 9.6 / 8.9 mm | 33.5°/s | 6% | 3.68 Hz |
| 只加滤波（缩放 1.0） | +3.2° / +6.1° | 14.0 / 13.0 mm | 39.0°/s | 7% | 2.80 Hz |
| 缩放 0.83 + 滤波（= 真机设置） | −1.3° / +0.1° | 11.1 / 10.4 mm | 37.4°/s | 9% | 3.31 Hz |
| 再加到 820 g | **−3.4° / −3.5°** | **7.4 / 7.3 mm** | 37.2°/s | **96%** | **4.10 Hz** |
| **真机** P4 / D0 / 681 | **−4.5° / −2.6°** | **4.8 / 5.8 mm** | 43.7°/s | 6% | 3.01 Hz |

读法：
- **缩放 0.83 是撑地膝盖伸不直 de 大头**：动作整体小了 17%，Modelo要「伸直」 de 那一Inferior也小了。只改这一项，膝盖就从 +3.5° / +6.5° 掉到 −0.6° / +1.5°；
- **滤波反而让脚抬得更高**：步频从 3.1 降到 2.8 Hz，步子变慢变大。所以两样一起加，离地只比早Superior低 1.5～1.6 mm；
- **再按 kissqy 训练Modelo de  820 g 加重**，撑地膝盖 −3.4° / −3.5°，跟真机 de  −4.5° / −2.6° 差不多了；离地 7.4 / 7.3 mm，还比真机高 2 mm EsquerdoDireito。Atenção这 83 g 我们全加在躯干Superior，kissqy  de Modelo是分在腿Superior、头Superior de （§4）；
- **但这时仿真变成 4.1 Hz  de 碎步，颤占 96%**，真机 D0 不是这样。仿真里还有几种情况也会变成这种碎步加颤：脚底太滑（§6）、飞特Parâmetros配 P3（§3）、飞特Parâmetros加重 200 g 以Superior（§4）。真机为什么不这样，没查，可能跟仿真里 de ServoModelo、关节摩擦有关。这一条没弄清以前，仿真 de 数字只能当方向看。

**能拿去用 de **：缩放 0.83 → 1.0 这一项，仿真里效果很大（带滤波时：离地 11.1 / 10.4 → 14.0 / 13.0 mm，撑地膝盖 −1.3° / +0.1° → +3.2° / +6.1°）。真机Superior能做 de 是把联合缩放从 0.9 改成 1.0（V164 里这个联合Modelo默认就是 1.0，R17 是 0.9），但还要乘电压补偿：8.0 V 时实际只从 0.83 升到约 0.925，加 11%，仿真里是加 20%。按线性估，真机 de 提升大约只有仿真 de 一半（仿真没跑 0.925 这一组）。10-13 夜 [§7.5](HD1910-20261013-夜-掉电-ServoD e 蹭地.md#75-Inferior一步一次只改一样) 第 3 条本来就打算试它。缩放大了电流也大，要先把供电弄好（10-13 夜 §2）。
