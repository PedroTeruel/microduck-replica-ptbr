## 装配结构

```
躯干主体 199g
├─ 左髋 yaw→roll 23g → 左髋 roll 6g → 左大腿 48g → 左小腿 22g → 左踝+脚 30g
├─ 颈根 37g → 颈俯仰件 6g → 头 yaw/roll 机构 49g → 头部总成+喙 189g
└─ 右髋 yaw→roll 23g → 右髋 roll 6g → 右大腿 48g → 右小腿 22g → 右踝+脚 30g

整机 737.2g   外形 144 × 141 × 264 mm
```

躯干e头几乎一样重（199g vs 189g）——**Cabeça占整机四分之一，重心很高**，
这解释了为什么它 de Caminhada策略难训。

## 关节Parâmetros

每条腿 5 个自由度，头颈 4 个 —— **14 个受控**。
整机实际装 **15 个 Dynamixel XL330**：第 15 个驱动喙/Inferior颚，走被动连杆，不进动作空间。

| 关节 | 行程 |
|---|---|
| `hip_yaw` | -25° ~ +30° |
| `hip_roll` | ±22° |
| `hip_pitch` / `knee` / `ankle` / `head_pitch` | ±90° |
| `neck_pitch` | -90° ~ +60° |
| `head_yaw` | ±170° |
| `head_roll` | ±25° |

## 从Execução时反推出 de 电控方案

<div align="center">
  <img src="../assets/hw/01-物理布局.png" alt="Microduck 电控总览：板子都装在哪" width="880">
  <br>
  <sub><b>五个模块 de 物理布局</b> —— 灰色虚线框是物理区域，实线框是模块，红色虚线框表示装在壳体<b>外面</b>。<br>
  <b>橙色</b>是Servo总线（自Superior而Inferior），<b>红色</b>是Bateria供电（自Inferior而Superior）。<br>
  最容易搞错 de 一条：<b>主控、HAT、摄像头三者都在头里</b>，摄像头距主控板 em 心约 13 mm 且 em 间没有关节 ——<br>
  所以 MIPI 排线不穿过脖子，真正过颈 de 是Servo总线e供电线。<br>
  <a href="../docs/Hardware入门.md">Completo图集 e 讲解 →</a>　·　<a href="../assets/hw/MicroduckHardware图集.pdf">Baixar PDF 图集（7 张，A3）</a></sub>
</div>


**一条 1 Mbps  de  TTL 串行总线搞定一切。**

```
                Radxa Zero 3W (RK3566) · Armbian
                  ├── UART2  1 Mbps TTL 单线半双工 ── 15× XL330 + imu_to_dxl (ID 200)
                  ├── I2C3   400 kHz (pin 3/5) ────── AIC3104@0x18 · ToF@0x29 · BMI088（未用）
                  ├── I2S3   12.288 MHz ───────────── 音频
                  ├── MIPI CSI ────────────────────── IMX219（I2C@0x10，转 90°）
                  ├── 蓝牙 ────────────────────────── 手柄 / 手机 App
                  ├── Wi-Fi ───────────────────────── WebRTC
                  └── USB-C ───────────────────────── 供电 + maskrom
```

| | |
|---|---|
| **主控** | **Radxa Zero 3W** —— 市售模块，**不是定制载板** |
| SoC | RK3566，四核 Cortex-A55，Mali-G52，0.8 TOPS NPU。Oficial公布 1 GB 内存 / 32 GB 存储；复刻买 1G 或 2G  de **无 eMMC** 版 + 32 GB microSD 卡即可，只走Oficial渠道，见 [电控Lista de compras](../docs/电控Lista de compras.md#该买哪个Configuração) |
| **舵机总线** | **单线半双工 TTL** —— **不是** RS-232，**也不是** RS-485。Dynamixel Protocol V2 @ 1 Mbps，走 `/dev/ttyS2` |
| **自制板 1** | **`imu_to_dxl` v2** —— 一颗会说 Dynamixel 的 LSM6DSV16X：总线 ID 200、寄存器 124，12 字节块在**同一次** `sync_read` 里和舵机一起读回 |
| **自制板 2** | **RPI Robot HAT** —— TLV320AIC3104 @ 0x18、一颗休眠的 BMI088、接 ToF 的 Stemma 座。**官方已开源**（[`elec_RPI_Robot_HAT`](https://github.com/pollen-robotics/elec_RPI_Robot_HAT)） |
| Bateria | 索尼 NP-F550，2S 锂电。**没有电量计，也没有 ADC** —— Bateria电压是**读ServoSuperior报 de 自身供电电压**得来 de  |
| 传感器 | LSM6DSV16X IMU · VL53L5CX/L8CX 8×8 ToF · IMX219（树莓派 Camera v2） |

`imu_to_dxl` 是整套设计里最漂亮的一手：**IMU 不走 I²C**，而是把自己伪装成一个 Dynamixel 从机，
于是姿态Dadose关节状态在同一次总线事务里回来 —— 不é necessário第二条总线，主机也不用跑姿态融合
（LSM6DSV16X  de 片Superior SFLP 块直接输出游戏旋转四元数，还自己估计陀螺零偏）。

**Completo细节：** [Hardware方案逆向](../docs/Hardware方案逆向.md) · [Hardware规格速查](../docs/Hardware规格速查.md)

⚠️ **仿真 STL ≠ 可打印工程件。** 仿真只关心外形 e 惯量，不保证配合公差、
螺纹孔、热熔螺母座e走线空间。直接打印大概率装不起来，é necessário自行补充工程细节。

💰 **自己造大概率比买贵，但差多少全看渠道。** 15 个 XL330 在 ROBOTIS 国际站约 **$359**、
美国站 **$412**、欧洲含税 **€603–629** —— 也就是从「略低于整机售价」到「远超」都有可能。
加Superior主控、Bateria、两块板打样e打印耗材必然更贵。Completo核价见 [BOM.md](../BOM.md)。

## 现实Caminho

放弃 100% 复刻（`imu_to_dxl` 板与可编辑机械 CAD 未开源），改成**机械照抄 + 电控自建**：

| | 方案 |
|---|---|
| 机械 | 到 [CAD 仓库](https://github.com/fanhao375/microduck-replica-cad) 选择对应舵机版本的模型与装配说明 |
| Servo | XL330 × 15，市售件照买 |
| 主控 | **Radxa Zero 3W**，市售模块， e Oficial同款 |
| IMU 板 | 自己画 `imu_to_dxl`：LSM6DSV16X + MCU + 半双工收发器，协议已还原 |
| HAT 板 | **Oficial Gerber 直接打样**（4 层板）。不要录音可整块省略，但**半双工方向电路要另配转接板**，见 [电控Lista de compras](../docs/电控Lista de compras.md#六两块-pcb) |
| Software | 主控同款则Oficial Rust Execução时可直接跑（Apache-2.0） |
| 策略 | 官方 9 个 ONNX 可用；改硬件后用 [microduck_rl](https://github.com/pollen-robotics/microduck_rl) 重训 |

**结论已从「Mecânica可抄、电控是硬墙」修正为「整机可复刻」** ——
主控是市售模块，自制板 de 功能eProtocolo已从源码Completo还原。
详见 [docs/Hardware方案逆向.md](../docs/Hardware方案逆向.md)。

## 三个必踩 de 坑

1. **Armbian 默认在 UART2 上跑登录控制台。** `serial-getty@ttyS2` 占着串口，
   必须 `systemctl mask` 掉。Pollen 是用 `fuser -v /dev/ttyS2` 查出来的。
2. **i2c3 e FUSB302 抢引脚。** 用排针 pin 3/5  de Hardware I²C，代价是**失去 USB-C PD 协商**
   （普通 5V 充电仍然可用）。
3. **NPU 出厂是关 de 。** Armbian 默认禁用，要跑 RKNN Modelo得刷 overlay 并重启。

## 重现

```bash
# 1. 为下列装配图生成脚本拉取上游（训练工程已在 software/training/，无需此步骤）
bash scripts/fetch_upstream.sh

# 2. 重新生成装配图
python scripts/render_assembly.py upstream/microduck_rl assembly-drawings

# 3. 导出上游装配分析预览（不作为实物打印件）
python scripts/export_assembly_stl.py upstream/microduck_rl analysis-output/cad-upstream

# 4. 重新扫描孔特征
python scripts/analyze_holes.py upstream/microduck_rl/src/mjlab_microduck/robot/microduck/assets
```

依赖：`mujoco` `numpy` `pillow` `scipy`。渲染需要可用的 OpenGL 上下文。
