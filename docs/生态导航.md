# Onde o Microduck está: navegação do ecossistema

**Chinês simplificado** · [English](ecosystem.en.md)

Os recursos do Microduck estão espalhados por várias organizações no GitHub e por três tipos de recurso no Hugging Face. **Os repositórios oficiais de hardware são fáceis de deixar passar**: não estão na organização principal e usam o prefixo `elec_`.

Este índice explica **o que é cada recurso e para que serve**. Dados verificados até **2026-09-04**; o número de estrelas pode mudar.

---

## I. Repositórios oficiais (pollen-robotics)

### Dois repositórios principais

| Repositório | Estrelas | Licença | Descrição |
|---|---:|---|---|
| [**microduck**](https://github.com/pollen-robotics/microduck) | 6982 | Apache-2.0 | **Runtime embarcado**. Todo o software que roda no robô, escrito em Rust: ciclo de controle de 50 Hz, atualizador, BLE, câmera/WebRTC, ToF e voz. Também é a referência das especificações de hardware: caminhos de dispositivos, endereços I²C e registradores estão definidos no código. |
| [**microduck_rl**](https://github.com/pollen-robotics/microduck_rl) | 1668 | Apache-2.0 | **Ambiente de treinamento por aprendizado por reforço** (baseado em mjlab). Contém **47 STL e o MJCF completo**; é a fonte única de toda a geometria. |

### Hardware (dois repositórios fáceis de não encontrar)

| Repositório | Estrelas | Licença | Descrição |
|---|---:|---|---|
| [**elec_RPI_Robot_HAT**](https://github.com/pollen-robotics/elec_RPI_Robot_HAT) | 15 | Apache-2.0 | ⭐ **Projeto completo de código aberto da placa HAT**. Esquemático e PCB KiCad 9, Gerber, BOM, coordenadas de montagem, STEP e manuais de todos os componentes. **Não é preciso desenhar a placa: baixe `production/` para fabricar** (placa de quatro camadas). |
| [**lib_KiCAD**](https://github.com/pollen-robotics/lib_KiCAD) | 3 | — | Biblioteca de símbolos, footprints e modelos 3D do KiCad da Pollen. **Instale-a antes de abrir o projeto acima**, senão os símbolos não serão resolvidos. |

> É comum pensar que o “hardware Microduck não é aberto”; **a placa HAT é aberta**, mas fica fora do repositório principal.
> O que realmente não foi publicado: placa `imu_to_dxl`, CAD mecânico editável e BOM completa do robô.

### Complementares

| Repositório | Estrelas | Descrição |

## Por onde começar

| Objetivo | Recurso |
|---|---|
| Explorar primeiro | [Simulador web oficial](https://huggingface.co/spaces/pollen-robotics/microduck-simulator), pronto para usar no navegador |
| Ver a aparência e a montagem | [Modelos e instruções de montagem CAD](https://github.com/fanhao375/microduck-replica-cad); a renderização de montagem neste repositório serve apenas como referência de análise do upstream |
| Imprimir peças | [Repositório CAD](https://github.com/fanhao375/microduck-replica-cad); [aviso de versões](../print/README.md) |
| Entender o controle eletrônico | [`docs/硬件方案逆向.md`](硬件方案逆向.md) neste repositório |
| Fabricar a placa HAT | Diretório `production/` de [`elec_RPI_Robot_HAT`](https://github.com/pollen-robotics/elec_RPI_Robot_HAT); instale antes a biblioteca `lib_KiCAD` |
| Treinar uma política | [`microduck_rl`](https://github.com/pollen-robotics/microduck_rl); sem GPU Nvidia, use [microduck-lab](https://github.com/jonathanhawkins/microduck-lab) |
| Consultar especificações de hardware | Código-fonte [`microduck`](https://github.com/pollen-robotics/microduck) — **o código é a especificação** |
