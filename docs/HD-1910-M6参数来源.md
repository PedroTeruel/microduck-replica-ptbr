## 怎么用

训练代码、参数、模型和接入修复统一放在本仓库 **[`software/training/`](../software/training/)**，
克隆或Baixareste repositório即可取得Completo工程。[Instruções de uso e Registro de validação](../software/training/docs/hd1910-baseline.md)
包含Comando、TesteResultado，e飞特Controle器目标Histórico初始化问题 de 原因e修复。

- 参数文件原样保存，保留 `model: "m6"` 和 `actuator: "sts3215"`；后者选择
  BAM  de 飞特Controle器实现。upstream把型号写作 HLS1910，维护者已确认采用同款 1910。
- 配套训练设置：P=5、电压随机范围 7.4–8.0 V、压降Inferior限 7.0 V、延迟 3–6 个
  仿真步。`max_velocity=100` 用于放开目标斜率限制，并不是舵机真实空载转速。
- 新增独立的 `Mjlab-Velocity-{Flat,Rough}-MicroDuck-HD1910` 训练入口，便于与
  原 XL330 基线比较。Atual接入Preservado本地 Microduck 几何、关节顺序e默认姿态。
- 实机逐关节零位、方向e限位仍使用este projeto校准Resultado；不复制对方整机 de 编码器
  零位或现成 ONNX 作为可直接Superior机 de 策略。

## 飞特Oficial HD-1910 BAM

2026-10-14 收录。飞特 9 月底在 Gitee 公开了 [ftservo/ftservo-bam](https://gitee.com/ftservo/ftservo-bam)，是 [Rhoban/BAM](https://github.com/Rhoban/bam) 的派生（fork），Apache-2.0：

- **参数**：`bam/params/feetech_hd1910_7_4V/m1.json`～`m6.json`。m6 文件最后改动在提交 `79eff6d`（09-26），SHA-256 `81a441fb921130bcc9bcfbd9ee0c77e3c38d9ab758bc7e0559fb029c436355ba`；收录时仓库 HEAD 是 `4f7c0b0`（09-30）；
- **控制模型**：`bam/feetech/actuator.py` 的 `HD1910Actuator`，纯 P 控制：占空比 = clip(0.163 × P × 角度误差, ±0.97)，电源 7.4 V，没有限速，没有 D；
- **辨识**：摆臂挂负载，P 取 4、8、16、32、64，跑 4 条激励轨迹（`bam/feetech/all_record.py`）。

**跟陆吾 1910 M6 比**（前五行按 BAM 公式推算，后面是 JSON 里 de 原值，都不是实测）：

| | 陆吾 1910 M6 | 飞特 HD-1910 m6 |
|---|---|---|
| ControleModelo | 借用 STS3215（0.166 × 拟合增益系数 1.32） | 专门 de  HD1910（0.163） |
| 每 rad 误差、每单位 P  de 占空比 | 0.219 | 0.163 |
| P=5 时误差多大开始饱e | 0.88 rad | 1.19 rad |
| 7.4 V 堵转力矩 | 0.91 N·m | 1.37 N·m |
| 小误差静刚度（P=5） | 1.03 N·m/rad | 1.15 N·m/rad |
| 电机电阻 R | 4.91 Ω | 2.97 Ω |
| 转动惯量 `armature` | 0.00178 | 0.00183 |
| 驱动侧负载摩擦 `load_friction_motor` | 0.069 | 0.353 |
| 外部负载摩擦 `load_friction_external` | 0.158 | 0.043 |
| 指令延迟 `command_delay` | 6.0 ms | 1.0 ms |

`command_delay` 只是辨识时记下的值：本仓库锁定的 BAM 版本训练时不读它，延迟由训练配置的 `delay_min_lag`／`delay_max_lag` 另设（3～6 个仿真步）。

**接入时要Atenção**：
1. 官方 JSON 写的是 `"actuator": "hd1910"`，注册表里的键是 `"HD1910"`，大小写对不上，直接 `load_model` 会报 `KeyError`。在飞特的仓库里用，把 `actuator` 改成 `"HD1910"` 就能加载；也可以给飞特提个 issue；
2. 换算系数不同：飞特是 0.163（P=1 时 4000 计数误差对应 100% PWM，即 1 / (4000 × 2π / 4096) ≈ 0.163；出自飞特早期的说明文档，历史提交 `3c37f36`，后来删了），Rhoban 原版 STS3215 是 0.166。放进本仓库的训练工程（锁定的 Rhoban BAM `62bd8ce`）、借 sts3215 控制模型来算时，要改三处：`actuator` 改成 `"sts3215"`；`error_gain_ratio` 填 0.163 / 0.166 ≈ 0.98193；`max_velocity` 照陆吾那份填 100，放开目标限速（不写的话默认约 5.2 rad/s，飞特的模型没有限速）。填 100 时每个物理步仍最多跳 0.5 rad，跟陆吾那份一样，是近似；
3. 录数据脚本 `record.py` 只写 P（HD-1910 是地址 50）、目标速度 0 和目标位置；D、转矩限制、加速度都是舵机里原有的值。出厂 D=40 的话，D 的阻尼多半会被拟合进摩擦参数（推测，没验证）。用它训出来的模型，上机前要确认 D，最好问一下飞特；
4. 有几项摩擦参数停在拟合边界上：`load_friction_external_quad` 0.0099999（上界 0.01）、`friction_stribeck` 0（下界 0），`load_friction_motor_stribeck` 只有 1.7e-6，也贴着下界。贴边界不一定是错，但这几项的数值不宜直接当物理量解读。

este repositórioProjeto de treinamento现在仍用陆吾那份。把飞特Parâmetros接进Projeto de treinamento de 方案审过一轮，还没做；我们也还没在真机Superior比过两份哪份更准。
