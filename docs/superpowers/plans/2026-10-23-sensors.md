# Camera and ToF Implementation Plan

> **For agentic workers:** use subagent-driven-development for the independent service and browser units. User confirmed independent pages and navigation placement; keep work local.

**Goal:** Add usable camera and ToF pages between handpad and servos with truthful hardware states.

**Architecture:** Reuse mediad LAN WebRTC video and tofd read-only stream. Isolate sensor I/O from robot control. HTTP serves authenticated bounded snapshots and camera connection metadata; browser owns video lifecycle.

**Tech Stack:** Existing Python/Starlette, asyncio, TOML, Preact/HTM, native WebSocket/RTCPeerConnection, unittest + Node/Edge.
