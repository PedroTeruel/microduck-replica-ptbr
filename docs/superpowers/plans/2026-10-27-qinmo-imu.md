# Qinmo IMU-DXL Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development for implementation followed by spec and quality review. Steps use checkbox syntax.

**Goal:** Integrate explicit persistent Qinmo/Feetech support into the native runtime and matching Studio calibration display, retaining existing automatic legacy detection.

**Architecture:** A named bus data profile isolates scale/status/identity semantics from the existing wire protocol. The same profile propagates through discovery, motion, commissioning and calibration binding. Following the user's rejection of manual SSH setup, Studio offers one-time selection through a narrow, gated helper transaction and the existing commissioning wizard; there is no live runtime switch or arbitrary configuration editor.

**Tech Stack:** Rust1.99, current Feetech UART and serde/TOML, Python3.13/Preact, WSL/QEMU ARM build, specification-based PTY peers. No hardware, cloud or new runtime libraries.
