# 2026.10.28 软件更新与 Qinmo 使用说明

已有卡不用重烧 SD 卡。本版分两步：先在原“设置 → 软件更新”里安装网页 / 语音，再在重连后的同一页明确确认可选的主程序更新。网页版本变为 `2026.10.28`，不代表主程序已经更新。

软件包及一次性引导附件见 [2026.10.28 Release](https://github.com/fanhao375/microduck-replica/releases/tag/microduck-software-v2026.10.28)。镜像仍为原 20261027，本次没有新镜像。普通 FT6、IMU-to-DXL 等现有板卡继续保留“自动识别（现有板卡）”，无需为了原用法强制安装主程序。

## 已有“软件更新”入口

1. 打开鸭子原来的控制网址，进入“设置 → 软件更新”，设置并登录网页密码。
2. 点“检查更新 → 下载更新”。离线时先在电脑下载 `2026.10.28.software-update.tar`，再在同一页点“上传离线包”。需要的是完整签名软件包，普通源码压缩包不能替代。
3. **第一步仍沿用旧升级器的站好条件**：停止活动，按原流程站好、关闭运动策略，关闭语音监听和音乐，结束舵机会话、标定、录制、回放与动作任务，保持充足电量。下载后若条件不足，按页面原因处理并“重新验证”。
4. 验证通过后点“立即更新”。这一阶段只切换网页、匹配的小助手和语音；不会安装或重启主程序，也不会改变默认 IMU 类型。网页会短暂断开，等它重连，核对网页 / 语音版本为 `2026.10.28`。
5. 如需 Qinmo，**第二步先用手或支架承托鸭子并卸力**，确认策略已关闭，语音、音乐和会话已停止。第二步不要求重新站立或回 HOME。下方“主程序更新（可选）”会分别显示包是否包含主程序、实际运行身份是否核验及事务进度。
6. 勾选“我已扶稳承托鸭子、确认卸力……”后，点“确认安装主程序”。仅有已核验的受支持安装才允许安装；查看设置、第一阶段更新、保留自动识别都不会代替这次确认。
7. 等待主程序实际运行身份核验完成；网页断开时重新打开同一页查看。进入 IMU 页，“总线 IMU 类型”选择 `Qinmo · Feetech`，点“保存类型并重新连接”，按页面完成静止、前倾采样及摆正、低头方向验证。类型会保存到后续开机，不必每次选择。详细步骤见 [Qinmo IMU 网页使用](Qinmo-IMU-网页使用.md)。

主程序自动更新只支持**本项目已知的 20261027 原生基线**（以及核对已是本版目标的情况）。自定义 robotd、其他构建、未知启动方式需要维护者核验，不提供强制安装。尚未完成首次标定、旧版读不回健康状态或未知出厂状态时，第一阶段也可能拒绝准备检查；请维护者先确认兼容性和首次使用流程，不能伪造状态、跳过检查或为了通过升级而强行站立行走。受支持的启动恢复状态由主程序更新器判断并交回首次标定流程，页面不会把未知真实扭矩说成已测得卸力。

## 中断、失败与回退

安装由独立小助手执行，关闭浏览器或网页服务重启不等于取消。重连后以实际运行核验和持久事务记录为准，不要只看网页版本或重复点击。

主程序失败时会尝试恢复并核验旧二进制。若显示“主程序更新未完成”，继续承托卸力，在同一页重新勾选确认后点“恢复未完成的主程序更新”。恢复未完成时，运动、录制、回放、音乐、舵机和 IMU 写入保持禁止；急停、空格卸力和关闭语音 / 音乐仍保留。恢复被拒绝时保留现场信息，请维护者核对，勿删除保护文件或手动启动控制服务。

“退回上一版网页 / 语音”只回退这一软件层；不会降级已安装的主程序。后续自愿降级主程序不在本版范围内。

## 老卡没有更新入口

通过 SSH 安装一次兼容的升级入口和外置资源，再回到上述网页流程。下载同一 Release 的 `microduck-bootstrap-20261028.tar.gz`、对应 SHA256 和 `2026.10.28.software-update.tar`，按 Release 的 `bootstrap-README.txt` 与包内 README 核对资源及兼容性后操作。引导包包含发行公钥、ARM64 升级执行器、语音依赖 / 中文模型资源；公钥仍为原 `microduck-release-20261027.pub`，不更换信任根。引导安装本身仍受原准备检查约束，真实设备不要加离线构建参数。不要只复制网页文件，也不要把源码压缩包当引导包。第一次需要维护者协助核对卡的来源和状态；之后日常软件更新无需 SSH。

软件更新保留自己的模型、Wi-Fi、手柄配对、动作、标定和 AI Key，主程序更新不会改写现有参数与标定字节。安装新镜像覆盖旧卡不属于保留个人数据的软件更新方式。

## 验证范围

本版尚未完成实物升级、站立、行走或 Qinmo 实物验收；软件、模拟服务和浏览器验证不能代替这些实机确认。音乐头身跟拍仍待修复，自由 AI 人声对话尚未接入。原有本地“坐下 / 站起来”和 R3 行为参见 [20261027 语音说明](软件更新与语音使用说明-20261027.md)。
