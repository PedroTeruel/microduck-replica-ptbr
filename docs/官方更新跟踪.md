本次入档：**2026-10-25，日本时间（Asia/Tokyo）**。这里记录官方运行程序、训练工程、HAT 和情绪素材的更新，以及对飞特复刻方案的影响。正式版本、开发分支、待合并 PR 和官方展示分别标注。

**本次同步的是资料和适配建议。** 某项被记录在这里，不代表已经合进我们的源码或镜像；完成移植后，另补本仓提交、测试结果、镜像版本与实机验证范围。机器可读的比对基线见 [upstream-status.json](upstream-status.json)。

## 这次最值得关注什么

- **正式运行程序仍是 `daemon-v0.17.8`**，10 月 19 日发布；仓库 10 月 24 日有推送，不等于默认分支或正式版本已经升级。
- **摄像头**：弱网优先降帧率的开发补丁，以及编码器直接导入相机缓冲区的说明，值得在真实摄像头接入时核查。
- **动作与声音**：10 月 24 日的开发分支支持把情绪关键帧和声音作为技能播放，和我们的动作回放、声音联动方向相关。
- **模型管理**：新出现的待合并 PR 提供模型导入预演，以及带时间相位的技能策略，值得对照现有模型导入流程。
- **ToF**：官方公开了 8×8 深度传感器建图、搬动后重定位的实测文章与数据集，是后续定位功能的参考。

## 官方代码目前包含哪些部分

以下是运行程序的主要组成，属于功能导航，不表示本周全部新增。入口见[官方 README](https://github.com/pollen-robotics/microduck/blob/942e58e3aa6dbb28e7037203fff11866122c7567/README.md)。

| 部分 | 主要内容 | 对本项目的关系 |
|---|---|---|
| `robotd` 与策略 | 舵机总线、控制循环、ONNX 策略、站立行走与动作技能 | 飞特总线、IMU 和配置接口需要保留本项目适配 |
| `padd` / `netpadd` / `duckctl` | 实体手柄、局域网 UDP 手柄与电脑端控制 | 对照已有手柄和网页控制实现，逐项比较协议 |
| `mediad` / `tofd` | 摄像头 WebRTC 视频、画面元数据和深度传感器服务 | 对接 Studio 摄像头及 ToF 页面，分别验证真实硬件 |
| `configd` / `btd` / `updaterd` | 配网与身份、BLE 通信、签名升级和回滚 | 和复刻镜像的启动、网络及发布机制不同，分别评估 |
| `microduck_rl` / 模拟器 / 情绪素材 | MuJoCo、强化学习训练与 ONNX 导出；模拟环境；动作关键帧与声音 | 官方策略依赖对应硬件与训练配置，不能仅凭同名动作认定适用 HD-1910 |

## 官方新展示：8×8 ToF 建图

官方 10 月 23 日的 [SLAM 实测文章](https://pollen-robotics.com/microduck/blog/microduck-slam/)介绍：用头部 8×8 ToF 和腿部里程计建图，停车时匹配环境，在被抱走或坐下搬动后重新定位，并保存地图。头部摄像头不参与这套建图；外部摄像头和地面标记用于测量真实位置。文章还公开了实测数据集。

这是后续 ToF 功能的参考。本次记录状态为“官方展示与数据已公开”；本项目仍需核对代码发布位置、硬件型号、传感器安装姿态、时间延迟及飞特步态里程计，不能据此把本镜像标成已有 SLAM。

## 摄像头选型记录

对**瑞莎 Zero 3W + IMX219 路线**，官方 [`mediad/src/camera.rs`](https://github.com/pollen-robotics/microduck/blob/942e58e3aa6dbb28e7037203fff11866122c7567/mediad/src/camera.rs)及 [`sensor.rs`](https://github.com/pollen-robotics/microduck/blob/942e58e3aa6dbb28e7037203fff11866122c7567/mediad/src/sensor.rs)记载：约 3.05 mm M12 镜头、**约 62° 水平视场角**。代码中的安装旋转角度、仿真相机的垂直视角，均不是这个镜头选型角度。

购买时确认传感器、水平视场角、镜头高度、模组外形与排线。更换广角镜头后，应重新标定相机内参再用于视觉测距或定位。官方 beta 板另有 GC2093 路线，不混用 IMX219 的标定数据。

## 本项目建议的跟进顺序

1. **真实摄像头链路**：出图、帧率、温度、弱网行为与资源释放；核对上述视频补丁。
2. **模型导入与动作回放**：比较导入预演和相位技能契约，保留网页操作与现有飞特适配。
3. **情绪动作与声音**：先接关键帧与 WAV 同步播放，再评估麦克风触发、模仿等另一层功能。
4. **ToF 定位**：先验证真实测距，再研究里程计、建图与重定位。

## 后续记录方式

- 对照已入档的 SHA、正式版本、开发发布和 PR 合并状态检查变化；读取实际改动，不只看提交标题。
- 有实质变化时更新本文与 JSON 基线，保留日期、来源、上游状态、对本项目的影响及集成状态。
- 没有变化时不产生空提交；仅仓库 `pushed_at` 改变，也不直接判断为正式功能更新。
- 实机验证结论沿用[现有记录](历史更新.md)，官方代码更新不会自动改变我们的验证范围。
