# 舵机 ID 不在线，会导致热点不出现吗？

不会。当前镜像由 `microduck-netcheck` 管理 Wi-Fi 与回退热点，服务只依赖网络管理和首次初始化顺序，不依赖 `robotd`、舵机 ID 或总线 IMU 在线。首次初始化先创建热点配置，再尝试识别 I²C IMU；没有找到 IMU 也会完成热点配置。舵机未接、ID 未配好与无线热点应分开检查。

## 先确认是 Zero 3W 还是 Zero 3E

[瑞莎官方说明](https://docs.radxa.com/en/zero/zero3/getting-started/preparation)：**Zero 3W 有板载 Wi-Fi，Zero 3E 没有板载 Wi-Fi，使用以太网接口联网。** 如果确实是 3E，未增加无线硬件时就无法发出 Wi-Fi 热点。

本项目当前公开复刻镜像主要适配 Zero 3W，尚未验证 Zero 3E 的完整启动、网口与外接无线适配。处理器同为 RK3566 不等于内核、设备树和网络硬件可以直接通用。3E 应先核对系统是否启动并识别网口；使用外接无线网卡时还要确认驱动及 AP 模式支持。当前配网脚本使用 `wlan0`，外接网卡若出现为其他接口名，也需要单独适配。

## 系统能登录时，先读取这些信息

通过已可用的网线、SSH 或串口终端执行以下只读命令：

```sh
cat /proc/device-tree/model
nmcli -f DEVICE,TYPE,STATE,CONNECTION device
ip -br address
systemctl status microduck-firstboot microduck-netcheck NetworkManager --no-pager
journalctl -b -u microduck-firstboot -u microduck-netcheck -u NetworkManager --no-pager -n 80
```

- **3W 没有 `wlan0`**：先查板卡批次、无线驱动和设备树；改舵机 ID 不会让无线网卡出现。
- **`wlan0` 已连接家里的 Wi-Fi**：使用同一网络里的设备访问鸭子当前 IP 的 `8000` 端口；没有同时显示回退热点不代表系统未联网。
- **`wlan0` 存在但没有连接**：查看 NetworkManager 和 `microduck-netcheck` 日志，确认是否在尝试已保存网络、启动热点或报告失败。首次启动与连接尝试需要时间，不能仅凭指示灯判断。
- **`Microduck-xxxx` 热点已启动**：手机连接该热点后访问 `http://10.42.0.1:8000/`。看到“无互联网”提示也可以保留连接，热点用于本地控制。
- **3E 只有网口**：核对网口有没有获得 IP，再从同一网络访问；本项目没有完成该板型验收，不能直接承诺换卡或软件更新可以解决所有适配问题。

分享日志时保留上述设备/服务状态即可，不要公开 Wi-Fi 密码、SSH 私钥或 AI Key。

## 给群友的一句话

“热点不依赖舵机 ID。先确认你用的是 3W 还是 3E：3E 没有板载 Wi-Fi，不加无线网卡就不会有热点；咱们当前镜像主要适配 3W。确认板型后，再查网络接口和启动日志。”
