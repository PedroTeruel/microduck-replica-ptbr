# Qinmo IMU：网页选择与安装方向验证

这份功能目前仅完成本地软件验证，没有更新真实鸭子或已发布的镜像，也没有秦墨实物的站立、行走验收。

已有 FT6、IMU-to-DXL 继续默认自动识别。FT6 和自家小板使用已知身份；通用 Dynamixel 2.0 只确认兼容布局。Qinmo 的文档没有可核验的唯一厂商身份和自动单位识别依据，因此需要在同一个 IMU 页面选择一次。之后每次开机会沿用保存的类型，不需要重复选择；“已配置 Qinmo”不表示自动认证了厂商。

1. 双手扶稳鸭子，在网页点“失能（卸力）”，等主程序确认失能。正在启动、还没进入控制的受支持状态也可走恢复流程；这不代表网页知道真实扭矩已关闭。
2. 在 IMU 页的“总线 IMU 类型”选 `Qinmo · Feetech`，点“保存类型并重新连接”，再确认已扶稳。
3. 等页面回到标定模式，按原来的静止、前倾步骤采集并计算方向，再交给主程序完成摆正和低头验证。重新选择会清除旧方向的确认状态，不能跳过验证。
4. 验证完成后保留选定类型。原来在正常控制模式的会话会回到控制模式并失能；原来属于出厂标定的会话继续按首次使用清单“写进主程序”。

页面分别显示“配置类型”和“实际连接”。Qinmo 角速度采用“原始值 ÷ 16.4 °/s”；旧总线板采用“原始值 × 0.0175 °/s”。连接失败时仍可查看已保存类型、取消会话并恢复原参数。启动恢复的取消会停留在安全标定模式，可重新选择并验证，不会自动启动运动。

刷新页面或重启后，未完成的会话和原配置备份仍在。普通控制模式的取消恢复主 / saved 配置、原标定和原模式；失败时保留可恢复会话。舵机总线占用、软件更新、其他标定会话、活动或未知控制状态都会拒绝切换。

维护者需先安装匹配的新版 robotd 和 helper 0.7.2。支持证据是新增的 `configured_imu_profile` 诊断字段；缺少时页面明确提示更新主程序，不会写不受支持的配置。robotd 由维护者单独安装，未加入现有网页软件更新组件。用户在受支持的网页流程中无需 SSH 或编辑配置文件。当前首版仅支持 Feetech 舵机总线的 Qinmo，未支持 Qinmo 的 DXL2 模式；I²C 芯片沿用原流程。

事务限制与测试见 [helper 安装说明](../software/studio/deploy/INSTALL.md) 和 [软件验证记录](superpowers/verification/2026-10-27-qinmo-studio.md)。
