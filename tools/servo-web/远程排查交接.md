## 2. 21 号（Esquerdo髋 roll）

**背景**：同事用 FD Depuração时 21 号出了事，断电后舵盘拧不动，怀疑烧了。出厂过流保护默认关着，只开了过热（80 °C）。堵转时一直吃大电流，等不到过热保护动作就可能先坏了。

### 2.1 先比手感（不Superior电）

Por favor同事断电，用同样 de 力拧 21 号e 20 号 de 舵盘。HD-1910 减速比 1:320，好 de Servo断电也基本拧不动。

- 20 号也拧不动：手感Instruções不了问题，接着测
- 20 号能拧、21 号纹丝不动：大概率齿轮崩了卡死，ou关节被别住

### 2.2 单独接Superior读

Por favor同事把 21 号从腿Superior拆Inferior来（至少拔掉别 de Servo de 线），总线Superior只接它一颗，再Superior电。

```bash
python servo_report.py --port COMx --ids 21
```

- **PING 不通**：再跑 `--scan-all`，ID 可能变了。还不通，驱动大概率烧了，这颗到此为止，记下来。
- **通了**：看状态位 65 哪一位亮、19、温度、电流、电压。

### 2.3 小幅动一Inferior（要主人同意）

只有 2.2 能读通才做。

```bash
python server.py --port COMx --ids 21
```

主人在浏览器开 http://127.0.0.1:8080：

1. 「单颗操作 → 写寄存器」选 48（转矩限制），值 300（= 30%），**不勾「解锁写」**。48 在 SRAM，断电就恢复。
2. 勾Superior扭矩。0.15.0 会先把目标对准Atual位置，不会动。
3. 滑块往一边拖 50 EsquerdoDireito（约 4°），看黄线e电流。

怎么判断：

| 现象 | 结论 |
|---|---|
| 能跟着转 | Servo本身是好 de ，问题在关节MecânicaSuperior（装配别住、撞限位） |
| 有电流但不转 | 齿轮卡死 |
| 没电流也不转 | 驱动或电机坏了 |

做完关扭矩，关Depuração台。21 号要换新 de ，看第 4 节最后。

## 3. 保护设置（要主人拍板）

体检里 19 缺过流、过压 de ，按《Registro de depuração》第 5 步应该打开：

- 值 = 原值 + 8 + 1（缺哪个加哪个）。出厂是 4  de 写 13。
- 过载（32）要不要也开（出厂 4 → 45），问主人。

方法：Depuração台「单颗操作」→ 选Servo →「写寄存器」选 19，填值，**勾「解锁写」**（EEPROM），点写。Página会回读核对。逐颗写。也pode在 FD 编程页勾过流、过压保护再保存。

写完关Depuração台，重跑一遍整机体检，确认没有红项了。

## 4. 折叠校准（做不做、今天做不做，主人定）

**前提**：15 颗都在线、体检没有红项、Depuração台是 0.15 起。细节见 [README](README.md)  de 一键校准e《Registro de depuração》「缩着能不能当标定基准」一节。

1. 全部关扭矩，鸭子趴在平桌Superior。3D 叠加选「校准用折叠」，照着摆。
2. 按这个顺序摆。膝在哪碰Superior跟髋 de 角度有关，所以先定髋：
   1. 髋 yaw、roll 摆正：腿不外撇、不外张
   2. 髋 pitch：直角尺把大腿摆到跟躯干垂直
   3. 踝 0°：脚板跟小腿成直角
   4. 膝往里折，折到踝刚好贴Superior大腿Superior de Servo就停，别顶着使劲
   5. 再用直角尺复查一遍髋
   6. 脖子竖直、头平视朝正前、不歪，嘴闭Superior
3. 基准选「Oficial折叠（头颈摆正）」，15 颗全选，点「一键校准」。
   - 确认框里正常每颗差几度。
   - 差 30° 以Superior de 先停，分清原因：装舵盘时转了半圈（照常校），还是 ± 设反了（先核：扭矩关着用手掰一Inferior，看 3D 是不是往同一边转）。
4. 校完读数应该是 22/23 = 1025、12/13 = 3071，其余 2048。
5. 用手把腿展开，托住鸭子，开扭矩（不会跳）。Oficial姿势点「零位」，过渡 3 秒，托着看：
   - 腿一条直线、脚板跟小腿垂直、EsquerdoDireito对称、头平视。
   - 差一两度 de ：扭矩开着用滑块调正，点「校准这一颗」，基准选「零位 2048」。最可能要调 de 是踝e髋 roll，它们在折叠时是靠眼睛摆 de 。
6. 点「站」，看站不站得稳、EsquerdoDireito对不对称。
7. 断电再Superior电，同一个姿势读数Inalterado，Instruções偏移写进 EEPROM 了。

**21 号换新Servo de 话**，校准前先按顺序做完：

1. 总线Superior只接新Servo，Depuração台「改 ID」改成 21
2. 转到 2048
3. 舵盘朝关节伸直 de 方向装，齿对不准取最近 de 
4. 开过流、过压保护（第 3 节）
5. 装回腿Superior后核 ±：扭矩关着用手掰，看 3D 转向

## 附：背景速查

- **ID**：20–24 Esquerdo腿（髋 yaw / roll / pitch、膝、踝），30–34 颈 pitch、头 pitch / yaw / roll、嘴，10–14 Direito腿。1 Mbps，单线半双工，URT-2。
- **方向**：15 颗全 −1，2026-09-20 实机核过，存在 `directions.json`。
- **零点**：Oficial 2048 = 腿伸直Ficar em pé（MJCF 关节全 0）。Oficial代码e策略不加补偿。
- **寄存器**：

  | 地址 | Conteúdo |
  |---|---|
  | 19 | 卸载条件：1 电压、2 磁编码、4 过热、8 过流、32 过载 |
  | 65 | 状态位，跟 19 同一套位 |
  | 28–29 | 保护电流，×6.5 mA |
  | 38 / 35 / 36 | 过流保护时间 / 保护时间 / 过载扭矩（%） |
  | 13 | 温度Superior限 |
  | 9–12 | 最小 / 最大角度限制 |
  | 31 | 位置偏移，BIT15 = 负 |
  | 48 | 转矩限制，1000 = 100%，SRAM |
  | 63 / 69 | Atual温度 / Atual电流（×6.5 mA） |

- HD-1910（Firmware 3.46）不认「扭矩开关写 128」这种 em 位校准，Depuração台用 0x0B。
