**Não misture peças de encaixe da Feetech com as do XL330.** Os dois servos usam formatos diferentes de horn. Os arquivos STL que ficavam neste repositório vinham da simulação upstream do XL330 e não incluíam as peças adaptadas para Feetech.

Em 2026-09-28, os STL antigos foram removidos deste diretório para evitar que fossem baixados e impressos por engano. Os arquivos antigos ainda podem ser consultados no histórico do Git, mas não são mais oferecidos como pacote de impressão atual. O repositório principal não mantém uma segunda cópia dos arquivos de modelos para download.

Consulte a seção correspondente no repositório CAD para ver os arquivos mais recentes de cada versão, a data de atualização, o material de impressão e as instruções para variantes com rodas. SolidWorks / STEP são arquivos CAD de origem; 3MF é o projeto de impressão. Antes de fatiar, confira a versão do servo, a impressora e o material.

As malhas mantidas em `software/training/` e no painel de depuração web do repositório principal servem para simulação e visualização, **não para fabricação**. Esta alteração não atualizou essas malhas, massas ou momentos de inércia para corresponder ao CAD físico mais recente.
